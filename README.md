# AI Skin Specialist

AI Skin Specialist is a Gradio-based consultation assistant that accepts a patient voice description plus a skin image and/or video, transcribes the patient's speech, sends the visual and text context to an AI vision model, and returns both a written and spoken doctor-style response.

**Important:** This project provides general informational guidance only. It is not a medical diagnosis and should not replace care from a licensed dermatologist or clinician.

## How It Works

```
Patient speaks (microphone)
        |
        v
voice_of_the_patient.py --> Groq Whisper API --> text transcript
        |
        v
brain_of_doctor.py --> image + (frame extracted from video) + transcript --> Groq vision model --> doctor-style text response
        |
        v
voice_of_the_doctor.py --> Deepgram TTS API --> audio file (doctor_response.mp3)
        |
        v
main.py (Gradio UI) --> shows transcript, text response, and audio playback
```

## Tech Stack

| Stage | Tool / API | Why |
|---|---|---|
| Web UI | Gradio | Fast way to build an interactive Python-native demo |
| Speech-to-Text | Groq Whisper (`whisper-large-v3`) | Very fast inference, generous free tier |
| Vision + Reasoning | Groq (`qwen/qwen3.6-27b`) | Multimodal (image) understanding, fast + free tier |
| Text-to-Speech | Deepgram (`aura-2-thalia-en`) | Natural-sounding, low-latency speech synthesis |
| Video frame extraction | OpenCV | Groq's vision models do not accept video directly, so a representative frame is extracted and sent as an image instead |
| Alternate provider | MiniMax (via Anthropic-compatible API) | Optional path with native video understanding (paid) |
| Dependency management | uv | Fast, reproducible Python environment + lockfile |

## Requirements

- Python 3.11 or newer
- [uv](https://docs.astral.sh/uv/) package manager
- FFmpeg (audio conversion/playback, used by `pydub`)
- PortAudio (bundled with the Windows `pyaudio` wheel; installed separately on macOS/Linux)
- API keys: Groq and Deepgram (MiniMax optional)

## Install System Dependencies

### Windows

1. Install [Chocolatey](https://chocolatey.org/install) (requires an **Administrator** PowerShell window).
2. Install FFmpeg:
   ```powershell
   choco install ffmpeg
   ```
   PortAudio does not need a separate install on Windows — the `pyaudio` wheel bundles it.
3. Close and reopen your terminal so the updated PATH is picked up. If `ffmpeg -version` still isn't recognized, restart your machine (Windows sometimes needs a full reboot to apply a machine-level PATH change).

### macOS

```bash
brew update
brew install ffmpeg portaudio
```

### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install ffmpeg portaudio19-dev python3-dev build-essential
```

## Setup

```bash
uv sync
```

This reads `pyproject.toml` and `uv.lock`, creates `.venv`, and installs all locked dependencies.

## Environment Variables

Copy the template and fill in your keys:

```bash
cp sample.env .env
```

```dotenv
GROQ_API_KEY=your_groq_api_key_here
DEEPGRAM_API_KEY=your_deepgram_api_key_here

# Optional model overrides
WHISPER_MODEL=whisper-large-v3
GROQ_MODEL=qwen/qwen3.6-27b
DEEPGRAM_TTS_MODEL=aura-2-thalia-en

# Optional — only needed for brain_of_doctor_minimax.py
MINIMAX_API_KEY=your_minimax_api_key_here
MINIMAX_BASE_URL=https://api.minimax.io/anthropic
MINIMAX_MODEL=MiniMax-M3
```

Do not commit real API keys to version control.

## Run the App

```bash
uv run python main.py
```

Gradio will print a local URL, usually `http://127.0.0.1:7860`. Open it in your browser.

## How to Use

1. Record or upload a patient voice description.
2. Upload a skin image and/or a short video.
3. Click **Analyze Concern**.
4. Review the transcript, doctor's guidance, and generated audio response.

## Known Limitations

- **Groq does not accept video input on any model.** To still make use of an uploaded video, `brain_of_doctor.py` extracts a single representative frame (via OpenCV) and sends it alongside the patient's image. This gives partial context from the video but not true motion/sequence understanding.
- **True video understanding requires MiniMax-M3** (`brain_of_doctor_minimax.py`), which natively accepts video through its Anthropic-compatible API. This is a paid service — new accounts get limited trial credits only, there is no permanent free tier.
- `qwen/qwen3.6-27b` is a **preview** model on Groq and can be renamed, changed, or deprecated at short notice. If you see a `model_not_found` error, check `https://console.groq.com/docs/models` for the current vision-capable model and update `GROQ_MODEL` in `.env`.
- Deepgram TTS rejects text over 2000 characters; responses are truncated with a safety margin before being sent for speech synthesis.

## Troubleshooting

**`ModuleNotFoundError: No module named 'groq'` (or similar)**
A dependency wasn't installed. Run:
```bash
uv add groq deepgram-sdk gradio pillow pydub pyaudio sounddevice SpeechRecognition opencv-python
```

**`ffmpeg not found` after installing via Chocolatey**
Close and reopen your terminal. If it still isn't found, restart your computer — PATH changes sometimes need a full reboot on Windows.

**`groq.NotFoundError: model does not exist`**
The model in `GROQ_MODEL` has been deprecated. Check the current model list and update your `.env`.

**`groq.RateLimitError` on output tokens**
Your `max_completion_tokens` request exceeds the free-tier per-minute limit for that model. Lower it, or disable reasoning with `reasoning_effort="none"` (already set for `qwen/qwen3.6-27b` in this project) so the model doesn't spend its token budget on a hidden `<think>` block before answering.

**Deepgram `Input text contains no characters`**
The upstream model's response ended up empty after removing its reasoning trace, usually because it ran out of tokens mid-thought. Increasing `max_completion_tokens` (within your rate limit) or disabling reasoning effort fixes this.

**Microphone not detected**
- Check OS-level microphone permissions.
- Confirm your browser has microphone permission for the local Gradio URL.
- Confirm no other app is holding the microphone.

## Security

- Keep `.env` private and never commit real API keys.
- Treat patient images, videos, and audio as sensitive data.
- This project has no defined data retention policy — add one before any real-world use.
